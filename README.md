# homebrew-cli

Homebrew tap for [Maton](https://maton.ai) CLI tools.

## Usage

```sh
brew install maton-ai/cli/maton
```

Or tap first, then install:

```sh
brew tap maton-ai/cli
brew install maton
```

## Updating

```sh
brew update
brew upgrade maton
```

## About

Formulas in this tap are published automatically by [goreleaser](https://goreleaser.com/) from the [maton-cli](https://github.com/maton-ai/cli) release pipeline.
